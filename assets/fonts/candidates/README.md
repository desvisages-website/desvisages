# Biography font candidates — not active on the website

These files are staged for the owner's screenshot comparison only. The published HTML and CSS still use Aujournuit for the biography; do not change the live font until the owner selects one.

The comparison renders Miedinger Book, Swansea Regular and Anderson Grotesk Regular at the same viewport, point size, line height and paragraph justification, changing only the biography body font. The Apfel Grotezk Mittel heading and photograph stay unchanged. These first comparisons use the regular/book cuts only. All three regular cuts cover every character in the current biography.

## Miedinger*

- Author/source: [indestructible type — Miedinger](https://github.com/indestructible-type/Miedinger).
- Original Book, Book Italic, Bold and Bold Italic OTF files are included. Asterisks were removed from the filenames only; font binaries are unchanged.
- License: the upstream SIL Open Font License 1.1 is preserved in `miedinger/LICENSE.md`.
- Upstream revision: `d79ca0e672eaabae4639c52004d4c09c8597b93a`. Chromium loads Book successfully but rejects the original Book Italic with a CFF CharStrings validation error. The original italic file is retained for reference; do not activate it on the web without a validated replacement.

## Swansea

- Designer: Roger White. The four unmodified TTF cuts come from the owner's `swansea.zip`.
- [UNCUT's Swansea record](https://uncut.wtf/sans-serif/swansea/) identifies the family as public domain and links to the designer's archived terms. [The designer statement reproduced with Swansea](https://www.1001freefonts.com/swansea.font) says the fonts are now public domain for personal and commercial use despite older notices in the font files, and requests acknowledgement for commercial use.
- The supplied ZIP contains no separate license document; the original font metadata is retained. This source note preserves attribution rather than relabelling Swansea as OFL.

## Anderson Grotesk

- Designer: Stephen French. The four unmodified OTF cuts come from the owner's `Anderson Grotesk.zip`.
- [The designer's project page](https://www.behance.net/gallery/58071711/ANDERSON-GROTESK-A-free-font-family) expressly states: “Free for personal and commercial use.”
- The supplied ZIP contains no separate license document. This records the designer's permission statement and source; it does not describe the font as OFL or public domain.
